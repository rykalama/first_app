# Project Layout

This project is a single-file web app.

- `AGENTS.md` contains project instructions.
- `spec.md` contains the project specification.
- `prompts.md` records requests and outcomes.
- `index.html` contains the complete web app and must remain at the top level for GitHub Pages.
- `00_planning/` contains notes, sketches, and planning materials.
- `01_data/` contains data files used by the project.
- `02_validation/` contains hand calculations and test cases.
- `03_output/` contains screenshots and exported results.

Save new files in the folder that matches their purpose. Keep app implementation in `index.html`; do not create additional app source files.

After each request, add an entry to `prompts.md`: what I asked, what you changed, and whether it worked.
